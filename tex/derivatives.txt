Second derivative of \psi wrt c:

    dt*w*(-2*x*g' - w*(dt + x^2*g') + 2*g*(1 + w*x)*(dt + dt*w*x + z'))
    = dt*w*((2*g*(1 + w*x)^2 - w)*dt - g'*x*(2 + w*x) + 2*g*(1 + w*x)*z')
    = (2*g*w*(1 + w*x)^2 - w^2)*dt^2 - g'*w*x*(2 + w*x)*dt + 2*g*w*(1 + w*x)*z'*dt


Second derivative of \psi wrt u:

    w^2*(-1 - x^2*g' + 2*g*x*(w*x + z'))
    = w^2*(2*g*w*x^2 - 1) - g'*w^2*x^2 + 2*g*w^2*x*z'
